# نظام مخازن — تعليمات مختصرة

هذا المستودع هو واجهة إدارة مخازن بسيطة تعتمد على Firebase (Firestore).

نقاط مهمة:
- كل أسماء المجموعات في قاعدة البيانات يجب أن تُبَدأ بالبادئة `stock_` (مثال: `stock_products`).
- توجد خدمة Firebase محورية في `/src/services/firebase-service.js` والتي تُهيئ الاتصال وتصدّر واجهة التعامل مع المجموعات.
- `firebase-init.js` الآن يقوم بتحميل الخدمة المركزية ويعرض `window.firebaseHelpers` للتوافق مع الكود الحالي.
- يوجد مكون `productPicker` في `/src/components/productPicker.js` لاستخدامه عبر الصفحات بدلًا من نسخ نفس الـ modal.

تشغيل محلي:
1. افتح الملفات HTML في متصفح (يفضل خادم محلي مثل `npx http-server .`)
2. تأكد أن مكتبات Firebase مُحمّلة في صفحات HTML (الملفات الحالية تفعل ذلك).

نشر وأمن:
- لا تعتمد على كون مفاتيح Firebase سرية؛ عوضًا عن ذلك أَمِن قواعد Firestore (انظر `firebase.rules.example`).
- قبل النشر، راجع قواعد Firestore وقيّد الكتابة/القراءة حسب الأدوار.

المزيد من التحسينات الموصى بها (قيد التنفيذ): توحيد مكونات UI في `src/components/`، وإضافة bundler (esbuild/rollup) لتجميع وتقليل الملفات.
