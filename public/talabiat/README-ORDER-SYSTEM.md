# نظام إدارة الطلبيات الذكي

نظام شامل لإدارة الطلبيات والمخازن مع واجهة مستخدم حديثة ومتجاوبة.

## 📋 نظرة عامة

يوفر النظام أدوات شاملة لإدارة عمليات الطلبيات والمخازن، مع دعم متعدد الفروع والأقسام، وواجهة مستخدم حديثة مبنية على تقنيات الويب الحديثة.

## ✨ المميزات الرئيسية

### 🏢 إدارة متعددة الفروع
- دعم فروع متعددة (الدقي، العبور، التجمع، القربة)
- إدارة مستقلة لكل فرع
- انتقال سريع بين الفروع

### 📊 لوحة التحكم الرئيسية
- إحصائيات فورية للطلبيات والأقسام والأصناف
- روابط سريعة للوصول لجميع أجزاء النظام
- عرض بصري جذاب مع تأثيرات glassmorphism

### 🛒 منشئ الطلبيات
- تصفح كتالوج الأصناف بالأقسام
- إضافة وحذف الأصناف بسهولة
- حساب تلقائي للإجماليات
- بحث متقدم في الأصناف
- حفظ الطلبيات في قاعدة البيانات

### 📋 إدارة الطلبيات
- عرض جميع الطلبيات في جدول قابل للتمرير
- فلترة متقدمة حسب الفرع والتاريخ والقسم
- بحث نصي في الطلبيات
- عرض تفصيلي لكل طلبية
- حذف الطلبيات مع تأكيد
- تصدير البيانات إلى CSV

## 🛠️ التقنيات المستخدمة

### الواجهة الأمامية
- **HTML5**: هيكلة الصفحات
- **CSS3**: التصميم مع glassmorphism وتأثيرات متقدمة
- **JavaScript (ES6+)**: التفاعل والمنطق
- **SweetAlert2**: النوافذ المنبثقة والتأكيدات

### قاعدة البيانات
- **Firebase Firestore**: قاعدة بيانات NoSQL في الوقت الفعلي
- **Firebase Hosting**: استضافة الويب

### المكتبات والأدوات
- **Firebase SDK**: الاتصال بقاعدة البيانات
- **Google Fonts (Cairo)**: الخط العربي
- **Responsive Design**: دعم جميع الأجهزة

## 🚀 التثبيت والتشغيل

### المتطلبات
- متصفح حديث يدعم ES6+
- اتصال بالإنترنت (لـ Firebase)
- خادم محلي أو استضافة ويب

### الخطوات

1. **تحميل الملفات**
   ```bash
   git clone <repository-url>
   cd order-system
   ```

2. **إعداد Firebase**
   - إنشاء مشروع جديد في Firebase Console
   - تفعيل Firestore Database
   - تحديث إعدادات Firebase في `firebase-config.js`

3. **تشغيل النظام**
   - فتح `dashboard-orders.html` في المتصفح
   - أو رفع الملفات إلى خادم ويب

## 📱 الاستخدام

### إنشاء طلبية جديدة
1. الدخول إلى `order-builder.html`
2. اختيار الفرع والقسم
3. تصفح الأصناف وإضافتها للطلبية
4. تعديل الكميات حسب الحاجة
5. حفظ الطلبية

### إدارة الطلبيات
1. الدخول إلى `orders-management.html`
2. استخدام الفلاتر للبحث
3. عرض تفاصيل الطلبيات
4. حذف الطلبيات غير المرغوبة
5. تصدير البيانات عند الحاجة

## 🔧 التطوير والصيانة

### إضافة قسم جديد
1. إضافة البيانات في مجموعة `catalog`
2. تحديث قوائم الفلترة في الكود
3. اختبار الوظائف الجديدة

### إضافة فرع جديد
1. تحديث قوائم الفروع في جميع الصفحات
2. إضافة البيانات المطلوبة
3. اختبار التكامل

### تخصيص التصميم
- تعديل متغيرات CSS في `:root`
- تحديث الألوان والخطوط
- ضبط التأثيرات البصرية

## 🐛 الإبلاغ عن المشاكل

إذا واجهت أي مشاكل:
1. تحقق من اتصال الإنترنت
2. تأكد من إعدادات Firebase
3. فحص وحدة التحكم في المتصفح للأخطاء
4. تحقق من توافق المتصفح
