# 📁 مجلد نظام إدارة الطلبيات الذكي

## 📋 محتويات المجلد

هذا المجلد يحتوي على **نظام إدارة الطلبيات الذكي** المطور حديثاً مع واجهة مستخدم متطورة.

### 📄 الملفات الموجودة:

1. **`dashboard-orders.html`** - لوحة التحكم الرئيسية
   - إحصائيات فورية للطلبيات والأقسام
   - روابط سريعة لجميع أجزاء النظام
   - تصميم glassmorphism حديث

2. **`order-builder.html`** - منشئ الطلبيات
   - واجهة متطورة لإنشاء الطلبيات
   - شاشة كاملة مع جداول قابلة للتمرير
   - بحث متقدم وحساب تلقائي للإجماليات

3. **`orders-management.html`** - إدارة الطلبيات
   - عرض وفلترة الطلبيات
   - جداول قابلة للتمرير مع رؤوس ثابتة
   - تصدير البيانات وإدارة الطلبيات

4. **`README-ORDER-SYSTEM.md`** - دليل الاستخدام الشامل
   - تعليمات التثبيت والاستخدام
   - وصف المميزات والتقنيات المستخدمة
   - نصائح التطوير والصيانة

## 🚀 كيفية البدء:

1. افتح `dashboard-orders.html` في المتصفح
2. ستجد لوحة التحكم الرئيسية
3. استخدم الروابط للتنقل بين الأقسام
