# Project Renaissance

هذا مشروع HTML موجود بالفعل وأريد تطويره وتحديثه، وليس إنشاء مشروع جديد من الصفر.

المطلوب منك أولًا:

1. فحص جميع ملفات المشروع الحالية وفهم هيكل المشروع والكود الموجود.

2. فهم التصميم الحالي والـ UI/UX والصفحات والوظائف الموجودة.

3. عدم حذف أو إعادة كتابة أي جزء موجود إلا إذا كان ذلك ضروريًا لتنفيذ التعديلات المطلوبة.

4. الحفاظ على التصميم الحالي، الألوان، الخطوط، توزيع العناصر، أسماء الصفحات، والوظائف الحالية.

5. البناء والتطوير فوق الكود الحالي بدلًا من إنشاء مشروع جديد مشابه له.

6. قبل إجراء أي تغيير كبير، وضّح لي ما الذي ستقوم بتعديله ولماذا.

7. لا تقم بتغيير الـ framework أو هيكل المشروع بدون سبب تقني واضح.

8. إذا وجدت كودًا قديمًا أو غير منظم، قم بتحسينه تدريجيًا مع الحفاظ على النتيجة البصرية والوظائف الحالية.

في البداية لا تقم بأي تعديل.

قم فقط بتحليل المشروع الحالي وأعطني:

- هيكل الملفات.

- الصفحات الموجودة.

- الوظائف الموجودة.

- التقنيات المستخدمة.

- قاعدة البيانات أو الـ APIs إن وجدت.

- أهم المشاكل أو نقاط الضعف في المشروع.

- أفضل طريقة لتطويره مع الحفاظ على التصميم الحالي.

بعد أن تنتهي من التحليل سأعطيك التعديلات المطلوبة واحدة تلو الأخرى.
